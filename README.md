# การ์ดงานแต่ง

เว็บการ์ดเชิญงานมงคลสมรสออนไลน์ — เปิดจากมือถือได้ทันที ส่งต่อทาง LINE / Facebook ได้เลย

เป็นเว็บแบบ static ล้วน (HTML + CSS + JavaScript) ไม่มี build step ไม่ต้องติดตั้งอะไร
เปิดไฟล์ `index.html` ก็ใช้งานได้ทันที และ deploy ขึ้น GitHub Pages ได้ฟรี

---

## แก้ข้อมูลงานยังไง

ข้อมูลทั้งหมดอยู่ในไฟล์เดียวคือ **`assets/js/config.js`** แก้ที่นั่นที่เดียวพอ ไม่ต้องแตะ HTML

| หัวข้อ | ตัวแปรใน config.js |
| --- | --- |
| ชื่อบ่าวสาว / ชื่อพ่อแม่ | `couple.groom`, `couple.bride` |
| วันเวลางาน (ใช้กับนับถอยหลัง + ปุ่มเพิ่มลงปฏิทิน) | `startsAt`, `endsAt` |
| ข้อความวันที่ที่แสดงบนการ์ด | `dateLabelTh`, `dateLabelEn` |
| สถานที่ + แผนที่ | `venue` |
| กำหนดการ | `schedule` |
| โทนสีการแต่งกาย | `dressCode` |
| ช่องทางตอบรับ | `rsvp` |
| บัญชีร่วมแสดงความยินดี | `gifts` |
| รูปภาพ | `gallery` |

> `startsAt` ต้องเป็นรูปแบบ ISO 8601 พร้อมโซนเวลาไทย เช่น `'2026-12-12T09:00:00+07:00'`

### ใส่รูป

วางไฟล์รูปไว้ในโฟลเดอร์ `assets/img/` แล้วใส่ชื่อไฟล์ลงใน `gallery`
ถ้ายังไม่มีรูป ช่องจะแสดงเป็นกรอบว่างเขียนว่า "รอรูปภาพ" ไม่พัง

แนะนำย่อรูปให้กว้างไม่เกิน 1600px ก่อนอัปโหลด เพื่อให้เปิดบนมือถือได้ไว

### ใส่แผนที่

1. เปิด Google Maps หาสถานที่จัดงาน
2. กด **แชร์ → ฝังแผนที่** แล้วคัดลอกเฉพาะค่าที่อยู่ใน `src="..."`
3. วางลงใน `venue.mapEmbedUrl`
4. ส่วน `venue.mapUrl` ใส่ลิงก์แชร์ธรรมดา (ใช้กับปุ่ม "เปิดใน Google Maps")

ถ้าเว้น `mapEmbedUrl` ไว้ว่าง แผนที่ฝังจะถูกซ่อนอัตโนมัติ เหลือแค่ปุ่ม

### ตอบรับคำเชิญ (RSVP)

สร้าง Google Form แล้วเอาลิงก์ใส่ใน `rsvp.formUrl` หรือจะใส่แค่เบอร์โทร (`rsvp.phone`)
หรือลิงก์ LINE (`rsvp.lineUrl`) ก็ได้ ถ้าไม่ใส่อะไรเลย หมวดนี้จะถูกซ่อนทั้งหมวด

### ตัวเลือกเพิ่มเติม

ใน `options`:

- `showBismillah: true` — ขึ้นบิสมิลลาฮฺเหนือชื่อบ่าวสาว สำหรับงานแบบมุสลิม
- `backgroundMusic: true` — เปิดเพลงประกอบ (วางไฟล์ที่ `assets/audio/theme.mp3` แล้วตั้ง `musicSrc`)
  จะมีปุ่มเปิด/ปิดเพลงมุมขวาล่าง

## ดูผลลัพธ์บนเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ได้ตรง ๆ หรือรันเซิร์ฟเวอร์เล็ก ๆ (แนะนำ เพราะแผนที่ฝังจะทำงานถูกต้องกว่า):

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เผยแพร่ขึ้น GitHub Pages

repo นี้มี workflow `.github/workflows/pages.yml` เตรียมไว้แล้ว

1. ไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **GitHub Actions**
3. push ขึ้น branch `main` — เว็บจะขึ้นอัตโนมัติที่ `https://<username>.github.io/wedding/`

> ถ้า repo เป็น **private** จะเปิด GitHub Pages ได้เฉพาะบัญชี GitHub Pro/Team ขึ้นไป
> ถ้าใช้บัญชีฟรี ให้เปลี่ยน repo เป็น public ก่อน หรือ deploy ที่อื่นแทน เช่น
> Netlify / Vercel / Cloudflare Pages (ลากโฟลเดอร์ทั้งอันไปวางก็ใช้ได้เลย ไม่ต้องตั้งค่า build)

## สิ่งที่การ์ดมีให้

- ซองจดหมายหน้าแรก แตะเพื่อเปิดการ์ด
- ปกชื่อบ่าวสาว + วันที่
- คำเชิญ ชื่อ-นามสกุลเต็ม และชื่อบิดามารดาทั้งสองฝ่าย
- นับถอยหลังแบบเรียลไทม์ + ปุ่มเพิ่มลงปฏิทิน Google
- กำหนดการแบบไทม์ไลน์
- สถานที่ พร้อมแผนที่ฝังและปุ่มนำทาง
- โทนสีการแต่งกาย
- แกลเลอรีรูปภาพ
- ช่องทางตอบรับคำเชิญ
- บัญชีร่วมแสดงความยินดี พร้อมปุ่มคัดลอกเลขบัญชีและ QR
- รองรับมือถือเต็มรูปแบบ, สั่งพิมพ์เป็นกระดาษได้ (Ctrl/Cmd + P), เคารพ `prefers-reduced-motion`

## โครงสร้างไฟล์

```
index.html              โครงหน้าเว็บ
assets/css/style.css    สไตล์ทั้งหมด
assets/js/config.js     ← แก้ข้อมูลงานที่ไฟล์นี้
assets/js/main.js       ตรรกะการแสดงผล
assets/img/             รูปภาพ
```
