# การ์ดเชิญงานวะลีมะฮฺ — มุบีน & ฟาฮาดา

การ์ดเชิญออนไลน์งานวะลีมะตุลอุรุส เปิดจากมือถือได้ทันที ส่งต่อทางไลน์ / เฟซบุ๊กได้เลย

เว็บแบบ static ล้วน (HTML + CSS + JavaScript) ไม่มี build step ไม่ต้องติดตั้งอะไร
เปิด `index.html` ก็ใช้งานได้ทันที และ deploy ขึ้น GitHub Pages ได้ฟรี

**งาน:** วันอาทิตย์ที่ 15 พฤศจิกายน 2569 · มัสยิดฮี่ดายาตุสซาลี่กีน เมืองพัทยา จังหวัดชลบุรี

---

## แก้ข้อมูลยังไง

ข้อมูลทั้งหมดอยู่ในไฟล์เดียวคือ **`assets/js/config.js`** แก้ที่นั่นที่เดียวพอ ไม่ต้องแตะ HTML

| หัวข้อ | ตัวแปรใน config.js |
| --- | --- |
| ชื่อบ่าวสาว (ไทย / อาหรับ / อังกฤษ) | `couple` |
| บิสมิลลาฮฺ, คำเชิญ, คำบนซอง | `bismillah`, `inviteLine`, `coverWord`, `coverHint` |
| อายะฮฺ + คำแปล + ที่มา | `verse` |
| วันเวลางาน (ใช้กับนับถอยหลัง + ปุ่มเพิ่มลงปฏิทิน) | `startsAt`, `endsAt` |
| วันที่ที่แสดงบนการ์ด + วันที่ฮิจเราะฮฺ | `date` |
| กำหนดการ | `schedule` |
| สถานที่ + แผนที่ | `venue` |
| ฟอร์มตอบรับ | `rsvp` |
| ดุอาอ์ + ข้อความปิดท้าย | `dua`, `closing` |

> `startsAt` ต้องเป็นรูปแบบ ISO 8601 พร้อมโซนเวลาไทย เช่น `'2026-11-15T09:00:00+07:00'`
> ตัวนับถอยหลังและปุ่มเพิ่มลงปฏิทินอ่านค่าจากตรงนี้ ส่วน `date` เป็นแค่ข้อความที่แสดง — ถ้าเลื่อนวันงาน ต้องแก้ทั้งสองที่

### ใส่แผนที่ฝัง

1. เปิด Google Maps หามัสยิด
2. กด **แชร์ → ฝังแผนที่** แล้วคัดลอกเฉพาะค่าที่อยู่ใน `src="..."`
3. วางลงใน `venue.mapEmbedUrl`

ถ้าเว้นว่างไว้ แผนที่ฝังจะถูกซ่อน เหลือแค่ปุ่ม "เปิดแผนที่" ซึ่งใช้ `venue.mapUrl`
แนะนำให้เปลี่ยน `venue.mapUrl` เป็นลิงก์แชร์จริงจาก Maps จะพาไปหมุดตรงจุดกว่าการค้นหาด้วยชื่อ

### ฟอร์มตอบรับ

ฟอร์มทำงานได้ 2 โหมด สลับอัตโนมัติตามว่าตั้งค่า Supabase ไว้หรือยัง

**โหมดเริ่มต้น (ยังไม่ตั้งค่า Supabase)** — ปุ่มจะ **คัดลอกข้อความสรุปลงคลิปบอร์ด**
ให้แขกเอาไปวางส่งในไลน์ของเจ้าภาพ ไม่ต้องมีเซิร์ฟเวอร์อะไรเลย ข้อความที่ได้หน้าตาแบบนี้:

```
ตอบรับคำเชิญงานวะลีมะฮฺ มุบีน & ฟาฮาดา
ชื่อ: สมชาย ใจดี
สถานะ: มาร่วมงาน
จำนวน: 2 ท่าน
```

ถ้าใส่ `rsvp.lineUrl` (เช่น `https://line.me/ti/p/~xxxx`) ระบบจะเปิดไลน์ให้ต่อทันทีหลังคัดลอก

**โหมดเก็บข้อมูล (ตั้งค่า Supabase แล้ว)** — คำตอบจะถูกบันทึกลงฐานข้อมูลโดยตรง
และเจ้าภาพเปิดดูรายชื่อทั้งหมดได้ที่หน้า `/admin.html` ดูขั้นตอนหัวข้อถัดไป

## เปิดหน้าดูรายชื่อคนมางาน (Supabase)

หน้า **`admin.html`** เป็นหน้าสำหรับเจ้าภาพ แสดงยอดรวมจำนวนแขก รายชื่อผู้ตอบรับทั้งหมด
ค้นหาชื่อ กรองเฉพาะคนที่มา/ไม่มา ลบรายการที่ผิด และดาวน์โหลดเป็นไฟล์ CSV เปิดใน Excel ได้

ตั้งค่าครั้งเดียวประมาณ 5 นาที:

### 1. สร้างโปรเจกต์

สมัครที่ https://supabase.com (ฟรี) → **New project**
Region เลือก **Southeast Asia (Singapore)** จะใกล้ไทยที่สุด
ตั้งรหัสผ่านฐานข้อมูลแล้วเก็บไว้ (ใช้ตอนนี้ไม่ต้อง แต่เก็บไว้ก่อน)

### 2. สร้างตาราง

เปิด **SQL Editor → New query** → วางเนื้อหาทั้งหมดจากไฟล์ **`supabase/schema.sql`** → กด **Run**

ไฟล์นี้สร้างตาราง `rsvps` พร้อมเปิด Row Level Security ไว้ให้แล้ว

### 3. เอาคีย์มาใส่ใน config.js

เปิด **Project Settings → API** แล้วคัดลอก 2 ค่านี้ลงใน `assets/js/config.js`

```js
supabase: {
  url: 'https://xxxxxxxx.supabase.co',   // Project URL
  anonKey: 'eyJhbGciOi...',              // anon public
  table: 'rsvps',
},
```

> ทั้งสองค่านี้ **เปิดเผยได้ ไม่ใช่ความลับ** — ตาม policy ใน `schema.sql` คีย์นี้ทำได้แค่
> "เพิ่มคำตอบรับ" เท่านั้น อ่านรายชื่อไม่ได้ แก้ไม่ได้ ลบไม่ได้
> **ห้ามเอา `service_role` key มาใส่เด็ดขาด** — คีย์นั้นข้าม RLS ได้ทั้งหมด

### 4. สร้างบัญชีเจ้าภาพ

เปิด **Authentication → Users → Add user**
กรอกอีเมลกับรหัสผ่านที่จะใช้ล็อกอินหน้า admin แล้วติ๊ก **Auto Confirm User** ด้วย
(ถ้าไม่ติ๊ก จะล็อกอินไม่ได้จนกว่าจะยืนยันอีเมล)

จากนั้นไปที่ **Authentication → Sign In / Providers → Email**
แล้ว **ปิด "Allow new users to sign up"** เพื่อไม่ให้ใครสมัครบัญชีเข้ามาอ่านรายชื่อได้เอง

### 5. เสร็จแล้ว

เปิด `https://<โดเมนของคุณ>/admin.html` ล็อกอินด้วยอีเมลที่สร้างไว้ในข้อ 4

หน้า admin ไม่มีลิงก์จากหน้าการ์ด และใส่ `noindex` ไว้แล้ว แขกทั่วไปจะไม่เจอ
แต่ต่อให้เจอ URL ก็เข้าไม่ได้ถ้าไม่มีบัญชี

> ⚠️ **โปรเจกต์ Supabase แบบฟรีจะถูกพักอัตโนมัติถ้าไม่มีการใช้งานติดต่อกัน 7 วัน**
> ช่วงที่ยังไม่ได้ส่งการ์ดออกไป ควรเข้าหน้า admin สัปดาห์ละครั้งเพื่อกันโดนพัก
> (ถ้าโดนพักไปแล้ว เข้า dashboard กด Restore ได้ ข้อมูลไม่หาย แต่ระหว่างพักฟอร์มจะส่งไม่ได้)

### ส่วนเสริมที่ปิดไว้

- **แกลเลอรีรูป** — วางไฟล์ใน `assets/img/` แล้วใส่ชื่อไฟล์ในอาร์เรย์ `gallery` หมวดจะโผล่เอง
- **ร่วมแสดงความยินดี** — ตั้ง `gifts.enabled: true` แล้วเติมข้อมูลบัญชีใน `gifts.accounts`
  (มีปุ่มคัดลอกเลขบัญชีและใส่รูป QR พร้อมเพย์ได้)
- **เพลงประกอบ** — ตั้ง `options.backgroundMusic: true` แล้ววางไฟล์ที่ `assets/audio/theme.mp3`
  จะมีปุ่มเปิด/ปิดเพลงมุมขวาล่าง

หมวดไหนไม่มีข้อมูลจะซ่อนตัวเองอัตโนมัติ ไม่ต้องไปลบ HTML

## ดูผลลัพธ์บนเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เปิดไฟล์ `index.html` ตรง ๆ ก็ได้ แต่รันเซิร์ฟเวอร์จะทำงานถูกต้องกว่า
(แผนที่ฝังและการคัดลอกคลิปบอร์ดต้องการ secure context)

## เผยแพร่ขึ้น GitHub Pages

repo นี้มี workflow `.github/workflows/pages.yml` เตรียมไว้แล้ว

1. ไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **GitHub Actions**
3. push ขึ้น branch `main` — เว็บจะขึ้นอัตโนมัติที่ `https://<username>.github.io/wedding/`

> repo เป็น **private** อยู่ ถ้าจะเปิด GitHub Pages ต้องใช้บัญชี GitHub Pro ขึ้นไป
> บัญชีฟรีให้เปลี่ยน repo เป็น public ก่อน หรือ deploy ที่ Netlify / Vercel / Cloudflare Pages
> (ลากโฟลเดอร์ทั้งอันไปวางได้เลย ไม่ต้องตั้งค่า build)

## สิ่งที่การ์ดมี

- ซองจดหมายหน้าแรก แตะเพื่อเปิดการ์ด
- บิสมิลลาฮฺ + คำเชิญ + ชื่อคู่บ่าวสาวทั้งภาษาอาหรับและไทย
- อายะฮฺอัร-รูม 30:21 พร้อมคำแปลไทย
- วันที่แบบไทยและฮิจเราะฮฺ
- กำหนดการ (อะกัดนิกะห์ / วะลีมะฮฺ)
- สถานที่ + ปุ่มเปิดแผนที่ + ปุ่มเพิ่มลงปฏิทิน Google
- นับถอยหลังแบบเรียลไทม์
- ฟอร์มตอบรับ (บันทึกลง Supabase หรือคัดลอกไปวางในไลน์ ถ้ายังไม่ได้ตั้งค่า)
- หน้าเจ้าภาพดูรายชื่อผู้ตอบรับ ยอดรวมแขก ค้นหา กรอง ลบ และดาวน์โหลด CSV
- ดุอาอ์ปิดท้าย
- รองรับมือถือเต็มรูปแบบ, สั่งพิมพ์เป็นกระดาษได้ (Ctrl/Cmd + P), เคารพ `prefers-reduced-motion`

## โครงสร้างไฟล์

```
index.html              การ์ดเชิญ (หน้าที่ส่งให้แขก)
admin.html              หน้าดูรายชื่อผู้ตอบรับ (สำหรับเจ้าภาพ)
assets/css/style.css    สไตล์การ์ด (ธีมเบอร์กันดี–ทอง)
assets/css/admin.css    สไตล์หน้าเจ้าภาพ
assets/js/config.js     ← แก้ข้อมูลงานที่ไฟล์นี้
assets/js/main.js       ตรรกะของการ์ด
assets/js/supabase.js   ตัวช่วยคุยกับ Supabase (ใช้ร่วมกันทั้งสองหน้า)
assets/js/admin.js      ตรรกะหน้าเจ้าภาพ
assets/img/             รูปภาพ
supabase/schema.sql     ตาราง + สิทธิ์การเข้าถึง เอาไปวางใน SQL Editor
```

ฟอนต์ที่ใช้ (โหลดจาก Google Fonts): **Aref Ruqaa** และ **Amiri** สำหรับภาษาอาหรับ,
**Charm** และ **Noto Sans Thai** สำหรับภาษาไทย, **Cormorant Garamond** สำหรับภาษาอังกฤษ
