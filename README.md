# การ์ดเชิญงานวะลีมะฮฺ — มุบีน & ฟาฮาดา

การ์ดเชิญออนไลน์งานวะลีมะตุลอุรุส เปิดจากมือถือได้ทันที ส่งต่อทางไลน์ / เฟซบุ๊กได้เลย

เว็บแบบ static ล้วน (HTML + CSS + JavaScript) ไม่มี build step ไม่ต้องติดตั้งอะไร
เปิด `index.html` ก็ใช้งานได้ทันที และ deploy ขึ้น GitHub Pages ได้ฟรี

**งาน:** วันอาทิตย์ที่ 15 พฤศจิกายน 2569 · มัสยิดฮี่ดายาตุสซาลี่กีน เมืองพัทยา จังหวัดชลบุรี

---

## แก้ข้อมูลยังไง

ข้อมูลทั้งหมดอยู่ในไฟล์เดียวคือ **`assets/js/config.js`** แก้ที่นั่นที่เดียวพอ ไม่ต้องแตะ HTML

| หัวข้อ | ตัวแปรใน config.js |
| --- | --- |
| ชื่อบ่าวสาว (ไทย / อาหรับ / อังกฤษ) | `couple` |
| บิสมิลลาฮฺ, คำเชิญ, คำบนซอง | `bismillah`, `inviteLine`, `coverWord`, `coverHint` |
| อายะฮฺ + คำแปล + ที่มา | `verse` |
| วันเวลางาน (ใช้กับนับถอยหลัง + ปุ่มเพิ่มลงปฏิทิน) | `startsAt`, `endsAt` |
| วันที่ที่แสดงบนการ์ด + วันที่ฮิจเราะฮฺ | `date` |
| กำหนดการ | `schedule` |
| สถานที่ + แผนที่ | `venue` |
| ฟอร์มตอบรับ | `rsvp` |
| ดุอาอ์ + ข้อความปิดท้าย | `dua`, `closing` |

> `startsAt` ต้องเป็นรูปแบบ ISO 8601 พร้อมโซนเวลาไทย เช่น `'2026-11-15T09:00:00+07:00'`
> ตัวนับถอยหลังและปุ่มเพิ่มลงปฏิทินอ่านค่าจากตรงนี้ ส่วน `date` เป็นแค่ข้อความที่แสดง — ถ้าเลื่อนวันงาน ต้องแก้ทั้งสองที่

### ใส่แผนที่ฝัง

1. เปิด Google Maps หามัสยิด
2. กด **แชร์ → ฝังแผนที่** แล้วคัดลอกเฉพาะค่าที่อยู่ใน `src="..."`
3. วางลงใน `venue.mapEmbedUrl`

ถ้าเว้นว่างไว้ แผนที่ฝังจะถูกซ่อน เหลือแค่ปุ่ม "เปิดแผนที่" ซึ่งใช้ `venue.mapUrl`
แนะนำให้เปลี่ยน `venue.mapUrl` เป็นลิงก์แชร์จริงจาก Maps จะพาไปหมุดตรงจุดกว่าการค้นหาด้วยชื่อ

### ฟอร์มตอบรับ

ปุ่ม "ส่งคำตอบรับ" จะ **คัดลอกข้อความสรุปลงคลิปบอร์ด** ให้แขกเอาไปวางส่งในไลน์ของเจ้าภาพ
(ไม่มีเซิร์ฟเวอร์ ไม่ต้องตั้งฐานข้อมูล) ข้อความที่ได้หน้าตาแบบนี้:

```
ตอบรับคำเชิญงานวะลีมะฮฺ มุบีน & ฟาฮาดา
ชื่อ: สมชาย ใจดี
สถานะ: มาร่วมงาน
จำนวน: 2 ท่าน
```

ถ้าใส่ `rsvp.lineUrl` (เช่น `https://line.me/ti/p/~xxxx`) ระบบจะเปิดไลน์ให้ต่อทันทีหลังคัดลอก

### ส่วนเสริมที่ปิดไว้

- **แกลเลอรีรูป** — วางไฟล์ใน `assets/img/` แล้วใส่ชื่อไฟล์ในอาร์เรย์ `gallery` หมวดจะโผล่เอง
- **ร่วมแสดงความยินดี** — ตั้ง `gifts.enabled: true` แล้วเติมข้อมูลบัญชีใน `gifts.accounts`
  (มีปุ่มคัดลอกเลขบัญชีและใส่รูป QR พร้อมเพย์ได้)
- **เพลงประกอบ** — ตั้ง `options.backgroundMusic: true` แล้ววางไฟล์ที่ `assets/audio/theme.mp3`
  จะมีปุ่มเปิด/ปิดเพลงมุมขวาล่าง

หมวดไหนไม่มีข้อมูลจะซ่อนตัวเองอัตโนมัติ ไม่ต้องไปลบ HTML

## ดูผลลัพธ์บนเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

เปิดไฟล์ `index.html` ตรง ๆ ก็ได้ แต่รันเซิร์ฟเวอร์จะทำงานถูกต้องกว่า
(แผนที่ฝังและการคัดลอกคลิปบอร์ดต้องการ secure context)

## เผยแพร่ขึ้น GitHub Pages

repo นี้มี workflow `.github/workflows/pages.yml` เตรียมไว้แล้ว

1. ไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **GitHub Actions**
3. push ขึ้น branch `main` — เว็บจะขึ้นอัตโนมัติที่ `https://<username>.github.io/wedding/`

> repo เป็น **private** อยู่ ถ้าจะเปิด GitHub Pages ต้องใช้บัญชี GitHub Pro ขึ้นไป
> บัญชีฟรีให้เปลี่ยน repo เป็น public ก่อน หรือ deploy ที่ Netlify / Vercel / Cloudflare Pages
> (ลากโฟลเดอร์ทั้งอันไปวางได้เลย ไม่ต้องตั้งค่า build)

## สิ่งที่การ์ดมี

- ซองจดหมายหน้าแรก แตะเพื่อเปิดการ์ด
- บิสมิลลาฮฺ + คำเชิญ + ชื่อคู่บ่าวสาวทั้งภาษาอาหรับและไทย
- อายะฮฺอัร-รูม 30:21 พร้อมคำแปลไทย
- วันที่แบบไทยและฮิจเราะฮฺ
- กำหนดการ (อะกัดนิกะห์ / วะลีมะฮฺ)
- สถานที่ + ปุ่มเปิดแผนที่ + ปุ่มเพิ่มลงปฏิทิน Google
- นับถอยหลังแบบเรียลไทม์
- ฟอร์มตอบรับที่คัดลอกข้อความให้ส่งต่อทางไลน์
- ดุอาอ์ปิดท้าย
- รองรับมือถือเต็มรูปแบบ, สั่งพิมพ์เป็นกระดาษได้ (Ctrl/Cmd + P), เคารพ `prefers-reduced-motion`

## โครงสร้างไฟล์

```
index.html              โครงหน้าเว็บ
assets/css/style.css    สไตล์ทั้งหมด (ธีมเบอร์กันดี–ทอง)
assets/js/config.js     ← แก้ข้อมูลงานที่ไฟล์นี้
assets/js/main.js       ตรรกะการแสดงผล
assets/img/             รูปภาพ
```

ฟอนต์ที่ใช้ (โหลดจาก Google Fonts): **Aref Ruqaa** และ **Amiri** สำหรับภาษาอาหรับ,
**Charm** และ **Noto Sans Thai** สำหรับภาษาไทย, **Cormorant Garamond** สำหรับภาษาอังกฤษ
