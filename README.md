# การ์ดเชิญงานวะลีมะฮฺ — มุบีน & ฟาฮาดา

การ์ดเชิญออนไลน์งานวะลีมะตุลอุรุส เปิดจากมือถือได้ทันที ส่งต่อทางไลน์ / เฟซบุ๊กได้เลย

เว็บแบบ static ล้วน (HTML + CSS + JavaScript) ไม่มี build step ไม่ต้องติดตั้งอะไร
เปิด `index.html` ก็ใช้งานได้ทันที และ deploy ขึ้น GitHub Pages ได้ฟรี

**งาน:** วันอาทิตย์ที่ 15 พฤศจิกายน 2569 · มัสยิดฮี่ดายาตุสซาลี่กีน เมืองพัทยา จังหวัดชลบุรี

## แก้ข้อมูลยังไง

ข้อมูลทั้งหมดอยู่ในไฟล์เดียวคือ **`assets/js/config.js`** แก้ที่นั่นที่เดียวพอ ไม่ต้องแตะ HTML

| หัวข้อ | ตัวแปรใน config.js |
| --- | --- |
| ชื่อบ่าวสาว (ไทย / อาหรับ / อังกฤษ) | `couple` |
| บิสมิลลาฮฺ, คำเชิญ, คำบนซอง | `bismillah`, `inviteLine`, `coverWord`, `coverHint` |
| อายะฮฺ + คำแปล + ที่มา | `verse` |
| วันเวลางาน (ใช้กับนับถอยหลัง + ปุ่มเพิ่มลงปฏิทิน) | `startsAt`, `endsAt` |
| วันที่ที่แสดงบนการ์ด + วันที่ฮิจเราะฮฺ | `date` |
| กำหนดการ | `schedule` |
| สถานที่ + แผนที่ | `venue` |
| ฟอร์มตอบรับ | `rsvp` |
| ดุอาอ์ + ข้อความปิดท้าย | `dua`, `closing` |

> `startsAt` ต้องเป็นรูปแบบ ISO 8601 พร้อมโซนเวลาไทย เช่น `'2026-11-15T09:00:00+07:00'`
> ตัวนับถอยหลังและปุ่มเพิ่มลงปฏิทินอ่านค่าจากตรงนี้ ส่วน `date` เป็นแค่ข้อความที่แสดง — ถ้าเลื่อนวันงาน ต้องแก้ทั้งสองที่

### ใส่แผนที่ฝัง

1. เปิด Google Maps หามัสยิด
2. กด **แชร์ → ฝังแผนที่** แล้วคัดลอกเฉพาะค่าที่อยู่ใน `src="..."`
3. วางลงใน `venue.mapEmbedUrl`

ถ้าเว้นว่างไว้ แผนที่ฝังจะถูกซ่อน เหลือแค่ปุ่ม "เปิดแผนที่" ซึ่งใช้ `venue.mapUrl`
แนะนำให้เปลี่ยน `venue.mapUrl` เป็นลิงก์แชร์จริงจาก Maps จะพาไปหมุดตรงจุดกว่าการค้นหาด้วยชื่อ

### ฟอร์มตอบรับ

ฟอร์มทำงานได้ 2 โหมด สลับอัตโนมัติตามว่าตั้งค่าระบบหลังบ้านไว้หรือยัง

**โหมดเริ่มต้น (ยังไม่ตั้งค่า)** — ปุ่มจะ **คัดลอกข้อความสรุปลงคลิปบอร์ด**
ให้แขกเอาไปวางส่งในไลน์ของเจ้าภาพ ไม่ต้องมีเซิร์ฟเวอร์อะไรเลย ข้อความที่ได้หน้าตาแบบนี้:

```
ตอบรับคำเชิญงานวะลีมะฮฺ มุบีน & ฟาฮาดา
ชื่อ: สมชาย ใจดี
สถานะ: มาร่วมงาน
จำนวน: 2 ท่าน
```

ถ้าใส่ `rsvp.lineUrl` (เช่น `https://line.me/ti/p/~xxxx`) ระบบจะเปิดไลน์ให้ต่อทันทีหลังคัดลอก

**โหมดเก็บข้อมูล (ตั้งค่าแล้ว)** — คำตอบจะถูกบันทึกลงฐานข้อมูลโดยตรง
และเจ้าภาพเปิดดูรายชื่อทั้งหมดได้ที่หน้า `/admin.html` ดูขั้นตอนหัวข้อถัดไป

## ตั้งค่าระบบหลังบ้าน

เว็บใช้ **Firebase** (Cloud Firestore + Authentication) เก็บข้อมูล และ **Cloudinary** เก็บรูปกับคลิป
ทั้งสองเจ้ามีแผนฟรีที่พอสำหรับงานแต่งหนึ่งงานสบาย ๆ ตั้งค่าครั้งเดียวประมาณ 10 นาที

> **ทำไมถึงเลือก Firebase** — Supabase แผนฟรีจะพักโปรเจกต์อัตโนมัติถ้าไม่มีการใช้งาน 7 วัน
> ซึ่งเสี่ยงมากกับงานที่ส่งการ์ดไปล่วงหน้าเป็นเดือน Firebase ไม่มีการพัก
>
> **ทำไมไม่ใช้ Firebase Storage** — โปรเจกต์ที่สร้างใหม่ต้องผูกบัตร (แผน Blaze) ก่อนถึงจะใช้ที่เก็บไฟล์ได้
> Cloudinary จึงเข้ามาแทนในส่วนของรูปและคลิป และยังแปลงฟอร์แมตวิดีโอให้อัตโนมัติด้วย

### 1. สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com → **Create a project** (ปิด Google Analytics ได้ ไม่ต้องใช้)
2. ในโปรเจกต์ กด **Build → Firestore Database → Create database**
   เลือกโหมด **Production mode** และ location **asia-southeast1 (Singapore)**
3. กด **Add app → Web (`</>`)** ตั้งชื่ออะไรก็ได้ แล้วคัดลอก `projectId` กับ `apiKey` จากโค้ดที่ขึ้นมา
4. เอาสองค่านั้นใส่ใน `assets/js/config.js`

```js
backend: 'firebase',
firebase: {
  projectId: 'wedding-xxxxx',
  apiKey: 'AIzaSy...',
},
```

> ทั้งสองค่า **เปิดเผยได้ ไม่ใช่ความลับ** — Firebase ออกแบบมาให้ฝังในหน้าเว็บอยู่แล้ว
> สิทธิ์จริงคุมด้วยกฎในข้อถัดไป

### 2. วางกฎความปลอดภัย

เปิด **Firestore Database → Rules** ลบของเดิมทิ้ง วางเนื้อหาทั้งหมดจาก **`firebase/firestore.rules`**
แล้วกด **Publish**

กฎนี้กำหนดว่า แขก (ไม่ได้ล็อกอิน) **เพิ่มข้อมูลได้อย่างเดียว** อ่านของคนอื่นไม่ได้ แก้ไม่ได้ ลบไม่ได้
พร้อมตรวจรูปแบบข้อมูลที่ส่งเข้ามาด้วย เพื่อกันการยัดข้อมูลขยะ

### 3. สร้างบัญชีเจ้าภาพ

เปิด **Build → Authentication → Get started → Email/Password** แล้วเปิดใช้งาน
จากนั้นแท็บ **Users → Add user** กรอกอีเมลกับรหัสผ่านที่จะใช้ล็อกอินหน้า `admin.html`

> ปิด **Email link (passwordless sign-in)** ไว้ และอย่าเปิด provider อื่น
> Firebase ไม่มีปุ่มปิดการสมัครสมาชิกโดยตรง แต่กฎในข้อ 2 อนุญาตให้ผู้ล็อกอินอ่านข้อมูลได้ทุกคน
> จึงไม่ควรเปิด provider ที่ใครก็สมัครเองได้

### 4. สร้างบัญชี Cloudinary

1. สมัครที่ https://cloudinary.com (แผนฟรี)
2. ที่ **Dashboard** จดค่า **Cloud name** ไว้
3. ไป **Settings → Upload → Upload presets → Add upload preset**
   - **Signing Mode: Unsigned** (สำคัญ)
   - **Folder:** `wedding-wishes`
   - บันทึกแล้วจดชื่อ preset ไว้
4. ใส่ใน `assets/js/config.js`

```js
media: { provider: 'cloudinary' },
cloudinary: {
  cloudName: 'dxxxxxxx',
  uploadPreset: 'ชื่อ preset ที่สร้างไว้',
  folder: 'wedding-wishes',
},
```

> **ห้ามเอา API Secret มาใส่เด็ดขาด** — โหมด unsigned ไม่ต้องใช้
> ข้อแลกเปลี่ยนของ unsigned preset คือใครอ่านโค้ดหน้าเว็บได้ก็อัปโหลดเข้าบัญชีคุณได้
> ถ้ากังวล เปิด **Settings → Upload → Upload presets → Access control** จำกัดขนาดและชนิดไฟล์เพิ่มได้

### 5. เสร็จแล้ว

เปิด `https://<โดเมนของคุณ>/admin.html` ล็อกอินด้วยบัญชีจากข้อ 3

ถ้ายังไม่ได้ตั้งค่าครบ หน้า `admin.html` และ `checkin.html` จะบอกตรง ๆ ว่าขาดค่าไหน ไม่ใช่ขึ้นหน้าเปล่า

### ถ้าอยากใช้ Supabase แทน

โค้ดรองรับทั้งสองเจ้า สลับได้ที่บรรทัดเดียวใน `config.js`

```js
backend: 'supabase',
media: { provider: 'backend' },   // เก็บไฟล์ใน Supabase Storage แทน Cloudinary
supabase: { url: '...', anonKey: '...' },
```

แล้วเอา `supabase/schema.sql` ไปรันใน SQL Editor ของ Supabase (สร้างตาราง สิทธิ์ และ bucket ให้ครบ)
ข้อดีคือเหลือบัญชีเดียวและไฟล์อยู่ใน bucket ปิดที่เปิดดูได้ผ่านลิงก์อายุ 1 ชั่วโมง
ข้อเสียคือโปรเจกต์จะถูกพักถ้าไม่มีคนใช้ 7 วัน และไม่มีการแปลงฟอร์แมตวิดีโอให้

## เช็คอินหน้างานด้วย QR + สมุดอวยพร

ส่วนนี้ใช้ระบบหลังบ้านชุดเดียวกับข้างบน ถ้าตั้งค่าเสร็จแล้วก็พร้อมใช้เลย

### แขกทำอะไรได้บ้าง

แขกส่องกล้องมือถือที่ป้าย QR หน้างาน → เปิดหน้า `checkin.html` แล้ว

1. **เช็คอิน** — กรอกชื่อ เลือกว่ามากันกี่ท่าน
2. **อวยพร** เลือกได้ 3 แบบ
   - **ข้อความ** — พิมพ์คำอวยพรส่งตรงถึงบ่าวสาว
   - **การ์ดรูป** — ถ่ายรูปหรือเลือกจากคลัง ใส่ข้อความ
     ระบบประกอบเป็นการ์ดอวยพรธีมเดียวกับการ์ดเชิญให้อัตโนมัติ (ไฟล์ 1080×1350)
   - **คลิปวิดีโอ** — อัดคลิปอวยพรจากกล้องหน้า ยาวไม่เกิน 30 วินาที

จะข้ามขั้นอวยพรก็ได้ กดปุ่ม "ไว้ทีหลัง" แล้วกลับมาสแกนใหม่ทีหลังได้ตลอด

### พิมพ์ป้าย QR

เปิดหน้า **`qr.html`** จากเว็บที่ deploy แล้ว

1. ช่อง "ลิงก์หน้าเช็คอิน" จะเติมลิงก์ของเว็บให้เองอัตโนมัติ (แก้ได้ถ้าต้องการ)
2. กด **สั่งพิมพ์** ได้ป้ายเต็มหน้า A4 ธีมเบอร์กันดี–ทอง มีชื่อบ่าวสาวและคำแนะนำ
3. หรือกด **ดาวน์โหลด PNG / SVG** เอาไฟล์ QR ไปวางในป้ายที่ออกแบบเอง

ตัวสร้าง QR เขียนไว้ในไฟล์ `assets/js/qrcode.js` ทำงานในเบราว์เซอร์ล้วน
ไม่ต้องต่อเน็ตไปเว็บสร้าง QR เจ้าไหน และไม่มีใครเห็นลิงก์ของคุณ

### เจ้าภาพดูอะไรได้

หน้า `admin.html` มี 3 แท็บ

| แท็บ | มีอะไร |
| --- | --- |
| ตอบรับคำเชิญ | ยอดรวมแขก ใครมา/ไม่มา ค้นหา กรอง ลบ ดาวน์โหลด CSV |
| เช็คอินหน้างาน | จำนวนคนที่มาถึงแล้ว รายชื่อพร้อมเวลาเช็คอิน |
| คำอวยพร | ข้อความ การ์ดรูป และคลิปทั้งหมด กรองตามประเภท ค้นหาได้ |

**ข้อมูลทั้งหมด** (ชื่อ คำอวยพร เวลา) อ่านได้เฉพาะบัญชีเจ้าภาพที่ล็อกอินแล้ว
คนที่ได้คีย์ในหน้าเว็บไปจะเพิ่มข้อมูลได้อย่างเดียว อ่านของคนอื่นไม่ได้

**รูปและคลิป** อยู่บน Cloudinary — URL เดายากแต่เป็นลิงก์สาธารณะ ใครได้ลิงก์ไปก็เปิดได้
ถ้าต้องการให้เข้มกว่านี้ ให้สลับไปใช้ Supabase Storage (ดูหัวข้อ "ถ้าอยากใช้ Supabase แทน")
ซึ่งไฟล์จะอยู่ใน bucket ปิดและเปิดดูได้ผ่านลิงก์อายุ 1 ชั่วโมงเท่านั้น

### ข้อจำกัดที่ควรรู้

- คลิปยาวได้ไม่เกิน **30 วินาที** และไฟล์ไม่เกิน 45 MB
- การอัดวิดีโอต้องใช้ **HTTPS** (หรือ localhost) และแขกต้องกดอนุญาตให้ใช้กล้อง/ไมค์
  ถ้าเบราว์เซอร์ไม่รองรับ หน้าเว็บจะบอกและให้เลือกส่งเป็นข้อความหรือรูปแทน
- iPhone อัดออกมาเป็น `.mp4` ส่วนแอนดรอยด์ส่วนใหญ่ได้ `.webm`
  Cloudinary จะแปลงให้ตามเบราว์เซอร์ของคนดูเอง (`f_auto`) จึงเปิดข้ามค่ายได้
- โควตาฟรีของ Cloudinary คิดรวมเป็นเครดิต (พื้นที่ + แบนด์วิดท์ + การแปลงไฟล์)
  งานแต่งหนึ่งงานปกติใช้ไม่ถึง แต่ถ้าคลิปเยอะมากควรโหลดเก็บลงเครื่องแล้วลบออกเป็นระยะ
- Firestore แผนฟรีอ่านได้ 50,000 ครั้ง/วัน — หน้า admin หนึ่งครั้งอ่านเท่าจำนวนแถว ใช้ไม่ถึงแน่นอน

### ส่วนเสริมที่ปิดไว้

- **แกลเลอรีรูป** — วางไฟล์ใน `assets/img/` แล้วใส่ชื่อไฟล์ในอาร์เรย์ `gallery` หมวดจะโผล่เอง
- **ร่วมแสดงความยินดี** — ตั้ง `gifts.enabled: true` แล้วเติมข้อมูลบัญชีใน `gifts.accounts`
  (มีปุ่มคัดลอกเลขบัญชีและใส่รูป QR พร้อมเพย์ได้)
- **เพลงประกอบ** — ตั้ง `options.backgroundMusic: true` แล้ววางไฟล์ที่ `assets/audio/theme.mp3`
  จะมีปุ่มเปิด/ปิดเพลงมุมขวาล่าง

หมวดไหนไม่มีข้อมูลจะซ่อนตัวเองอัตโนมัติ ไม่ต้องไปลบ HTML

## เผยแพร่ขึ้น GitHub Pages

repo นี้มี workflow `.github/workflows/pages.yml` เตรียมไว้แล้ว

1. ไปที่ **Settings → Pages**
2. ที่ **Source** เลือก **GitHub Actions**
3. push ขึ้น branch `main` — เว็บจะขึ้นอัตโนมัติที่ `https://<username>.github.io/wedding/`

> repo เป็น **private** อยู่ ถ้าจะเปิด GitHub Pages ต้องใช้บัญชี GitHub Pro ขึ้นไป
> บัญชีฟรีให้เปลี่ยน repo เป็น public ก่อน หรือ deploy ที่ Netlify / Vercel / Cloudflare Pages
> (ลากโฟลเดอร์ทั้งอันไปวางได้เลย ไม่ต้องตั้งค่า build)

- สถานที่ + ปุ่มเปิดแผนที่ + ปุ่มเพิ่มลงปฏิทิน Google
- นับถอยหลังแบบเรียลไทม์
- ฟอร์มตอบรับ (บันทึกลงฐานข้อมูล หรือคัดลอกไปวางในไลน์ ถ้ายังไม่ได้ตั้งค่า)
- เช็คอินหน้างานด้วยการสแกน QR พร้อมส่งคำอวยพรเป็นข้อความ การ์ดรูป หรือคลิปวิดีโอ
- หน้าเจ้าภาพดูผู้ตอบรับ คนที่มาถึงแล้ว และคำอวยพรทั้งหมด พร้อมดาวน์โหลด CSV
- ดุอาอ์ปิดท้าย
- รองรับมือถือเต็มรูปแบบ, สั่งพิมพ์เป็นกระดาษได้ (Ctrl/Cmd + P), เคารพ `prefers-reduced-motion`

## โครงสร้างไฟล์

```
index.html              การ์ดเชิญ (หน้าที่ส่งให้แขก)
checkin.html            เช็คอินหน้างาน + ส่งคำอวยพร (แขกเข้าผ่าน QR)
qr.html                 สร้างและพิมพ์ป้าย QR สำหรับวางหน้างาน
admin.html              หน้าเจ้าภาพ: ผู้ตอบรับ / เช็คอิน / คำอวยพร

assets/css/style.css    สไตล์การ์ด (ธีมเบอร์กันดี–ทอง)
assets/css/checkin.css  สไตล์หน้าเช็คอิน
assets/css/admin.css    สไตล์หน้าเจ้าภาพ

assets/js/config.js       ← แก้ข้อมูลงานและคีย์ที่ไฟล์นี้
assets/js/main.js         ตรรกะของการ์ด
assets/js/checkin.js      ตรรกะหน้าเช็คอิน (รวมการประกอบการ์ดรูปและอัดคลิป)
assets/js/admin.js        ตรรกะหน้าเจ้าภาพ
assets/js/qrcode.js       ตัวสร้าง QR code เขียนเอง ไม่พึ่งไลบรารีภายนอก

assets/js/backend.js      เลือกผู้ให้บริการตาม config แล้วประกอบเป็น window.BACKEND
assets/js/firebase.js     คุย Firestore + Auth ผ่าน REST
assets/js/supabase.js     คุย Supabase ผ่าน REST (ทางเลือกสำรอง)
assets/js/cloudinary.js   อัปโหลดรูป/คลิปขึ้น Cloudinary

assets/img/               รูปภาพ
firebase/firestore.rules  กฎความปลอดภัย เอาไปวางใน Firestore Rules
supabase/schema.sql       ตาราง สิทธิ์ และ bucket สำหรับกรณีใช้ Supabase
```

ฟอนต์ที่ใช้ (โหลดจาก Google Fonts): **Aref Ruqaa** และ **Amiri** สำหรับภาษาอาหรับ,
**Charm** และ **Noto Sans Thai** สำหรับภาษาไทย, **Cormorant Garamond** สำหรับภาษาอังกฤษ
